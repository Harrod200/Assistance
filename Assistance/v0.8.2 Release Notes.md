## Key Technical Details

### The Bug (Fixed)

**Before v0.8.2:**
```csharp
// WRONG: Double-counting
if (assistPercentage > 0f)
{
	// COUNT #1: assistBonus included here
	int rawAttribute = ...GetAttribute(...);
	additional += (rawAttribute + assistBonus) * assistPercentage;
}

if (assistBonus > 0)
{
	// COUNT #2: assistBonus added AGAIN here
	additional += assistBonus / 100f;
}

__result += additional;  // Both counts apply!
```

**After v0.8.2:**
```csharp
// CORRECT: Single application
if (assistBonus > 0)
{
	float assistPercentage = Main.settings.assistPercentage / 100f;
	float additional = (assistBonus * assistPercentage) / 100f;
	__result += additional;
}
```

### Impact Example

**Scenario:** Councilor with Science 80, assists another → 20 point bonus, 50% efficiency

| Calculation | v0.8.1 (buggy) | v0.8.2 (fixed) |
|---|---|---|
| Percentage boost | (80+20)*0.5 = 50 | (20*0.5)/100 = 0.1 |
| Vanilla scale | 20/100 = 0.2 | (included above) |
| **Total added to AdvisingBonus** | **50 + 0.2 = 50.2** | **0.1** |
| **Effect on nation** | ~2x inflated | Correct |

- All existing assist bonuses continue to work
- No save games are lost or corrupted

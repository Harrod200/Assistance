# Assistance Mission Mod

A Terra Invicta mod that adds an **Assist Mission** system, allowing one councilor to temporarily share a percentage of their stats with another councilor during missions.

## Features

### Core Functionality
- **Assist Mission Type**: New mission that enables stat sharing between two councilors
- **Configurable Assistance**: Set sharing percentage from 0-100% (default: 50%)
- **Temporary Bonuses**: Shared stat bonuses are temporary and expire after the assisted councilor completes their next mission
- **Flexible Combinations**: Works with any pair of councilors from the same faction

### Mission Details
- **Mission Name**: Councilor Assist
- **Mission Type**: Contested Mission
- **Participants**: One attacking councilor + one defending target (the assisted councilor)
- **Duration**: One turn
- **Success Condition**: Attack > Defense (standard contested mission rules)

### Stats Shared
When an assist mission succeeds, the assisted councilor temporarily gains:
- Loyalty
- Offense
- Defense  
- Research
- Economics
- Loyalty Recovery

### Accurate Mission Breakdown Display
The mod includes a sophisticated mission modifier caching system that ensures mission breakdowns accurately reflect the exact modifiers used during mission calculation, not post-mission modifications. This prevents reward bonuses from appearing in breakdown text and properly displays all modifiers including zero-valued ones like Crackdown.

## Installation

1. Extract the mod folder to: `Terra Invicta\Mods\Enabled\AssistMission\`
2. Ensure `Assistance.dll` is present in the mod folder
3. Ensure `ModInfo.json` is present in the mod folder
4. Launch Terra Invicta; the mod should load automatically

## Configuration

Edit `config.json` in the mod folder to customize:
- **Assistance Percentage**: Percentage of stats to share (0-100)
- **Assistance Duration**: How long bonuses persist (in mission count)

## Technical Details

### Mission Calculation
- Assist bonuses are calculated by `TIMissionResolution_Contested_AssistBonusPatch`
- Bonuses are tracked per-councilor by `AssistBonusTracker`
- Modifier snapshots are captured via `MissionCalculationCache` at calculation time to ensure accurate UI display

### Mission Breakdown
- Breakdown text is generated by `TINotificationQueueState_MissionDetailBreakdownPatch`
- Uses cached modifier lists captured during mission resolution
- Falls back to `GetNonZeroModifiers()` if cache is unavailable
- Cache auto-cleans entries after 1 minute

### Code Organization

**Core Patches:**
- `AssistBonusTracker.cs` - Tracks temporary stat bonuses per councilor
- `TIMissionResolution_Contested_AssistBonusPatch.cs` - Applies bonuses during contested mission resolution
- `TIMissionResolution_Contested_ModifierCachePatch.cs` - Captures modifier lists at calculation time
- `TINotificationQueueState_MissionDetailBreakdownPatch.cs` - Displays accurate mission breakdowns

**Mission Components:**
- `TIMissionTemplate_Assist.cs` - Defines the assist mission template
- `TIMissionEffect_Assist.cs` - Handles bonus application and cleanup
- `TIMissionModifier_AssistFlat.cs` - Flat stat bonuses
- `TIMissionModifier_AssistStat.cs` - Stat-based bonuses (offense, defense, etc.)
- `TIMissionCondition_*.cs` - Mission validity conditions

**UI Integration:**
- `CouncilorView_GetAttributeStringPatch.cs` - Displays current stat bonuses in councilor view
- `CouncilGridController_SetStatValuePatch.cs` - Shows bonuses in council grid
- `CouncilorMissionCanvasController_UpdateModifierListPatch.cs` - Updates mission modifier display
- `FinalizeCouncilorMissions_AssistPriorityPatch.cs` - Prioritizes assist missions

**Utilities:**
- `MissionCalculationCache.cs` - Transient cache for modifier snapshots
- `Settings.cs` - Configuration management
- `Main.cs` - Mod initialization and HarmonyLib patching
- `AssistMissionBootstrapPatch.cs` - Ensures mission template registration

## Troubleshooting

### Assist Bonuses Not Applying
- Verify the assist mission succeeded (attack > defense)
- Check that both councilors are from the same faction
- Ensure the assisted councilor hasn't completed another mission yet

### Mission Breakdown Shows Incorrect Modifiers
- This should not occur with v0.7.3+
- If it does, check the Player.log file for cache-related errors
- Verify the mod's DLL file is up to date

### Game Crash on Assist Mission
- Ensure you're using Terra Invicta v1.0.38 or later
- Check that all mod files are present (DLL, JSON, etc.)
- Review Player.log for HarmonyLib patch errors
